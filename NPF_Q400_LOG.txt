NPF-Q400 — Version pérenne v2026.54
Base : TEST v13.32
Objet : validation pérenne des corrections TEST v13.24 à v13.32

MODIFICATIONS INTÉGRÉES

1. Mise à jour / relance PWA
- Le message post-mise à jour précise que la relance peut être demandée plusieurs fois et que c’est normal.
- Le message conseille de supprimer puis réinstaller la PWA depuis Safari si l’application devient anormalement lente à s’ouvrir ou reste bloquée au démarrage.
- Le message est conservé sur deux ouvertures après mise à jour, pour tenir compte du comportement iPadOS/PWA observé.

2. Démarrage application
- Ajout d’un garde-fou pour éviter que l’écran « Chargement NPF-Q400 — Patience je réfléchis » reste bloqué indéfiniment.
- Conservation des améliorations du service worker pour limiter les blocages en réseau dégradé.

3. Carte / suivi GPS
- Le bouton « centrer la carte sur position » fonctionne comme un mode suivi GPS activable/désactivable.
- Bouton en vert pastel lorsque le suivi est actif.
- Si la carte est déplacée manuellement, le recentrage automatique intervient après 10 secondes.
- Correction du cas où le premier déplacement manuel recentrait immédiatement au lieu d’attendre 10 secondes.

4. Commune survolée / département
- Le nom de commune reste déterminé par le calque communes.
- Le département affiché est déterminé par le calque départements au même point GPS.
- Le département ne dépend plus d’une correspondance par nom seul dans le listing communes.
- Le code INSEE reste utilisé comme contrôle/secours lorsque nécessaire.
- Objectif : éviter les erreurs sur communes homonymes, par exemple Mérignac affiché avec un mauvais département.

5. Recherche des feux / historique
- Ajout d’un historique des feux repliable/dépliable.
- Flèche vers le bas pour afficher l’historique.
- Flèche vers le haut pour masquer l’historique.
- Lorsque l’historique est ouvert, la flèche reste à droite de « Tout effacer ».
- L’état affiché/masqué est mémorisé.

6. BLOC / FUEL et PRÉVI NBR ROTATION
- Dans BLOC/FUEL, la LIMITE HDV affichée se met à jour dès qu’un BLOC ARRIVÉE est saisi.
- Dans PRÉVI NBR ROTATION, la LIMITE HDV reprend automatiquement le restant actualisé.
- La limite journée de référence reste protégée en mémoire pour éviter une baisse définitive à chaque sauvegarde.
- Le tableau BLOC/FUEL conserve le calcul correct du Tps de Vol Restant sans double soustraction.

7. Version / cache
- Passage APP_VERSION en v2026.54.
- Mise à jour du cache service worker en sw-v2026-54.
- Mise à jour du cache départements en npf-q400-departments-v2026-54.
- Mise à jour des paramètres appv dans index.html et manifest.json.
